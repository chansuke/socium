# SOC-048: README の承認の説明を実装に合わせる

GitHub: なし (2026-11-19 の公開前レビューで発見)

## 問題
README は「Commands and edits ask first」と書いていたが、承認を求める編集はホストが実行するファイルだけで、ほかの編集は承認なしで書き込まれる。セキュリティの境界を実際より強く見せていた。`CONTRIBUTING.md` と `docs/daily-reliability.md` は、もう入っている web search を未実装と書いていた。

## 対応・受け入れ条件
- README に、承認を求めるもの (コマンド、コミット、ホストが実行するファイルの編集、秘密ファイルの読み取り) と、すぐ書き込まれて `/undo` で戻せる編集を分けて書く。
- web search の記述を今の状態に合わせる。
